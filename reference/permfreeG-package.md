# permfreeG: Permutation-Free Exact Nearest-Neighbour G CSR

Closed-form mean and variance of the sample-specific complete spatial
randomness (CSR) null distribution for the nearest-neighbour \\G\\
function, univariate
([`Gest`](https://rdrr.io/pkg/spatstat.explore/man/Gest.html)) and
bivariate cross
([`Gcross`](https://rdrr.io/pkg/spatstat.explore/man/Gcross.html)).

## Details

The null model permutes marks among a fixed set of spatial locations, so
the marked subset is a uniformly random subset of the observed point
pattern. This reproduces the permutation distribution exactly (up to
numerical precision) without enumerating permutations.
