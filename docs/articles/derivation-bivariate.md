# Derivation: exact mean and variance of the bivariate cross nearest-neighbour G function

This vignette proves the closed-form mean and variance of the bivariate
cross nearest-neighbour statistic G\_{ij} under a disjoint
label-permutation null, again without reference to code. The univariate
result of the companion vignette is recovered as the special case i = j.

## 1. The null model

The locations X = \\x_1, \dots, x_N\\ are fixed. Two marks (or two
phenotypes) i and j are present with observed counts n_i and n_j, and no
location carries both marks. The bivariate CSR null permutes the labels
among the locations while preserving those counts, so

S_i \sim \mathrm{Uniform}\\T \subset X : \|T\| = n_i\\,

and, conditionally on S_i,

S_j \sim \mathrm{Uniform}\\T \subset X \setminus S_i : \|T\| = n_j\\.

This requires n_i + n_j \le N, which the package checks.

The statistic measures how close type-i points are to type-j points,

G\_{ij}(r) \\=\\ \frac{1}{n_i} \sum\_{p \in S_i} \mathbf{1}\\\left\\
d(p, S_j) \le r \right\\, \qquad d(p, S_j) = \min\_{q \in S_j} \\x_p -
x_q\\,

with the convention that an empty minimum is +\infty (so a type-i point
with no type-j point within r contributes zero).

## 2. Indicator decomposition and the conditioning lemma

Put, for each location p,

A_p(r) = \\ q \neq p : \\x_p - x_q\\ \le r\\, \qquad m_p(r) =
\|A_p(r)\|,

and

Y_p \\=\\ \mathbf{1}\\p \in S_i\\ \cdot \mathbf{1}\\\left\\A_p(r) \cap
S_j \neq \emptyset\right\\.

Then G\_{ij}(r) = n_i^{-1} \sum_p Y_p. Unlike the univariate case, the
indicator involves *both* random sets.

**Lemma 4 (conditional uniformity).** Let T \subseteq X with \|T\| = t,
and condition on the event T \subseteq S_i. Then S_j is uniform over the
n_j-subsets of X \setminus T. In particular, for any fixed M \subseteq X
\setminus T with \|M\| = m,

\Pr\\\left(S_j \cap M = \emptyset \\\middle\|\\ T \subseteq S_i\right)
\\=\\ \frac{\binom{N-t-m}{n_j}}{\binom{N-t}{n_j}} \\=\\
T\_{N-t,\\n_j}(m).

*Proof.* The joint law of (S_i, S_j) is invariant under permutations of
X that preserve the marks, so it can be generated by ordering X
uniformly at random and taking the first n_i locations as S_i and the
next n_j as S_j. Conditional on the set of locations occupying the first
t positions being exactly T, the remaining N - t locations are in a
uniformly random order, so positions t+1,\dots,t+n_j form a uniform
n_j-subset of X\setminus T. Avoidance is then Lemma 1 applied to that
ground set. \square

## 3. Exact mean

**Theorem 3 (bivariate mean).**

\mathbb{E}\big\[G\_{ij}(r)\big\] \\=\\ \frac{1}{N} \sum\_{p=1}^{N}
\Big(1 - T\_{N-1,\\n_j}\big(m_p(r)\big)\Big).

*Proof.* By linearity, \mathbb{E}\[G\_{ij}(r)\] = n_i^{-1} \sum_p
\Pr(Y_p = 1). For fixed p,

\Pr(Y_p = 1) = \Pr(p \in S_i)\\ \Pr\\\left(A_p(r) \cap S_j =
\emptyset\\\middle\|\\ p \in S_i\right).

Now \Pr(p\in S_i) = n_i/N, and Lemma 4 with T = \\p\\ (so t = 1) and M =
A_p(r) \subseteq X\setminus\\p\\ gives

\Pr\\\left(A_p(r) \cap S_j = \emptyset\\\middle\|\\ p\in S_i\right) =
T\_{N-1,\\n_j}(m_p).

Multiplying by n_i/N and dividing the sum by n_i yields (1/N)\sum_p (1 -
T\_{N-1,n_j}(m_p)). \square

**Remark 5 (the mean depends only on n_j).** The type-i count n_i enters
Theorem 3 only through the prefactor 1/N, so it cancels: the expected
cross-G curve is unchanged if n_i changes, as long as n_j, and hence the
type-j mark, is fixed. This asymmetry is intuitive: how many type-i
points there are does not change the chance that a given one finds a
type-j neighbour. It is also visible in the implementation, where only
n_j enters the avoidance table.

## 4. Exact second moments

**Lemma 6 (pair inclusion, bivariate).**

\Pr(p \in S_i,\\ q \in S_i) = \frac{n_i(n_i-1)}{N(N-1)} \\=:\\
c_2^{(i)},

which is Lemma 2 applied to the uniform n_i-subset S_i.

For the joint probability of two hits, define the *punctured* neighbour
sets

A_p^{\ast} = A_p(r) \setminus \\q\\, \qquad A_q^{\ast} = A_q(r)
\setminus \\p\\.

These are the neighbours of p and q other than each other, so both are
subsets of the ground set X \setminus \\p,q\\ used by Lemma 4 with T =
\\p, q\\, t = 2. Write

u\_{pq} \\=\\ \big\| A_p^{\ast} \cup A_q^{\ast} \big\| \\=\\
m_p^{\ast} + m_q^{\ast} - w\_{pq},

where m_p^{\ast} = \|A_p^{\ast}\|, m_q^{\ast}=\|A_q^{\ast}\| and w\_{pq}
= \|A_p(r) \cap A_q(r)\|.

**Lemma 7 (two hits).**

\mathbb{E}\[Y_p Y_q\] = c_2^{(i)}\\ \Big(1 -
T\_{N-2,\\n_j}(m_p^{\ast}) - T\_{N-2,\\n_j}(m_q^{\ast}) +
T\_{N-2,\\n_j}(u\_{pq})\Big).

*Proof.* \\Y_p = Y_q = 1\\ requires p, q \in S_i, of probability
c_2^{(i)}, and then that S_j meets both A_p(r) and A_q(r). Conditional
on p,q\in S_i, Lemma 4 with T = \\p,q\\ says S_j is uniform over the
n_j-subsets of X \setminus \\p,q\\. On that ground set the relevant
neighbour sets are exactly A_p^{\ast} and A_q^{\ast}. By
inclusion–exclusion,

\Pr(\text{both met}) =
\frac{\binom{N-2-m_p^{\ast}}{n_j}}{\binom{N-2}{n_j}} \\+\\
\frac{\binom{N-2-m_q^{\ast}}{n_j}}{\binom{N-2}{n_j}} \\-\\
\frac{\binom{N-2-u\_{pq}}{n_j}}{\binom{N-2}{n_j}},

which is the stated bracket. \square

Note that, unlike the univariate case, there is no special short-cut
when \\x_p - x_q\\ \le r: the hit condition concerns S_j, not S_i. The
general formula already covers that situation, because then q \in A_p(r)
so m_p^{\ast} = m_p - 1, and the corresponding avoidance probability
decreases accordingly.

**Theorem 4 (bivariate variance).**

\mathrm{Var}\big(G\_{ij}(r)\big) \\=\\ \frac{1}{n_i^2}
\left\[\sum\_{p=1}^{N} e_p(1 - e_p) + 2\sum\_{p\<q}\big(f\_{pq} - e_p
e_q\big)\right\],

with e_p = (n_i/N)(1 - T\_{N-1,n_j}(m_p)) and f\_{pq} from Lemma 7.

*Proof.* Identical to Theorem 2, using the decomposition G\_{ij} =
n_i^{-1}\sum_p Y_p. \square

## 5. The diagonal case

When the two marks coincide, the natural reading of G\_{ii} is the
univariate nearest-neighbour statistic computed on a uniform subset of
size n_i: there is no independent S_j. The package implements G\_{ii} by
delegating to the univariate estimator with n = n_i, and Theorems 1–2
then apply verbatim. This is the correct reduction because in the
univariate problem the neighbour of a marked point may be any other
marked point, whereas in Lemma 7 S_j and S_i are disjoint.

## 6. Numerical illustration

For small patterns the bivariate null can be enumerated exhaustively:
for each of the \binom{N}{n_i} choices of S_i, run over all
\binom{N-n_i}{n_j} choices of S_j from the remaining locations. With N =
10, n_i = 4 and n_j = 3 this is \binom{10}{4}\binom{6}{3} = 210 \times
20 = 4200 configurations.

``` r

suppressPackageStartupMessages(library(permfreeG))
set.seed(11)
N <- 10; ni <- 4; nj <- 3
x <- stats::runif(N); y <- stats::runif(N)
radii <- seq(0, 1.2, by = 0.15)

D <- as.matrix(stats::dist(cbind(x, y)))
ci <- utils::combn(N, ni)
Gsim <- NULL
for (j in seq_len(ncol(ci))) {
  Si <- ci[, j]
  rem <- setdiff(seq_len(N), Si)
  cj <- utils::combn(length(rem), nj)
  for (k in seq_len(ncol(cj))) {
    Sj <- rem[cj[, k]]
    Gsim <- rbind(Gsim,
                  vapply(radii, function(rr)
                    mean(rowSums(D[Si, Sj, drop = FALSE] <= rr) > 0), numeric(1)))
  }
}

d <- data.frame(x = x, y = y,
                m = factor(c(rep("A", ni), rep("B", nj),
                             rep("C", N - ni - nj))))
res <- as.data.frame(exact_gcross(d, radii = radii, mark_col = "m",
                                  marks_i = "A", marks_j = "B"))

c(max_mean_error     = max(abs(res$csr_mean - colMeans(Gsim))),
  max_variance_error = max(abs(res$csr_var -
                               apply(Gsim, 2,
                                     function(z) mean((z - mean(z))^2)))))
#>     max_mean_error max_variance_error 
#>       5.273559e-16       3.070461e-16
```

Again the errors are pure floating-point round-off.

A direct check of Remark 5 is also immediate: changing n_i while holding
n_j fixed leaves the exact mean unchanged.

``` r

pp <- spatstat.geom::ppp(x, y,
                         window = spatstat.geom::owin(range(x), range(y)),
                         marks = d$m)
a <- permfreeG:::csr_cross_moments_cpp(x, y, radii, 4L, nj)
b <- permfreeG:::csr_cross_moments_cpp(x, y, radii, 5L, nj)
max(abs(a$mean - b$mean))
#> [1] 0
```
