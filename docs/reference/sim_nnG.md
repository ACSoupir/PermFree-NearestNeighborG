# Synthetic two-type point pattern

A small deterministic example with 30 points in the unit square, of
which five are marked `"A"`. It mirrors the simulated example in Soupir
et al. (2025) used to show that the exact CSR mean equals the average of
\\G(r)\\ over all `choose(30, 5) = 142506` marked subsets.

## Usage

``` r
sim_nnG
```

## Format

A data frame with 30 rows and three variables:

- x, y:

  Coordinates in the unit square.

- m:

  Mark factor with levels `"A"` (5 points) and `"B"`.
